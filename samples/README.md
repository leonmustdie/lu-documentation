# Sample files

Hand-authored assets created from scratch to demonstrate and test the
toolkit. They contain **no game data** — every byte is generated by
`make_sample.py` — and are released under the repository's license.

## `table_flat.lu`
A synthetic `.lu` archive: a simple table mesh (a tabletop on four legs)
plus a flat solid-colour DXT1 texture, written directly to the documented
container format in its *stored* (uncompressed) mode. Run the toolkit on
it to see the full extract → convert pipeline:

    python3 ../tools/naughty_lu.py extract table_flat.lu -o out/
    python3 ../tools/lu_convert.py  out/                 -o converted/
    # -> converted/.../*.obj  (the table)  +  *.png  (the flat texture)

## `make_sample.py`
The generator. Regenerate or recolour the sample:

    python3 make_sample.py -o table_flat.lu --color 166,124,90

Because the sample is authored forward from the format spec (not derived
from any game file), it doubles as a regression test: the geometry and
texture colour that come back out are known in advance.
